1. 暴力拼接存在的问题
• 截交线段拼接问题可以抽象为 ：对同一平面上 N条散乱无序的线段序列 ，将其首尾相连成M条多段线。
• 这里M  N，如果M = 1，则所有N条线段都将连接到同一条多段线上，如果M = N，则N条线段中无两条线段首尾坐标重合。
• 对三维打印这一具体应用来说，最终拼接得到的多段线应该还需满足首尾相接的要求，即它们应该是闭合的。
• 拼接的难点是由STL模型中三角面片的无序性造成的。
• 暴力拼接基本原理：对于当前拼接过程中的多段线，遍历线段序列，从头开始搜索能和当前多段线端点（起点或终
点）重合的那条线段，如果能够找到线段，只需将该线段拼接到多段线上，如果找不到线段，则对当前多段线来说，
拼接过程结束。
• 暴力拼接的问题：暴力拼接法在最优的情况下，仍需要经历n(n+1)/2次搜索和坐标比对，其中n为线段序列中的线段
数量，即暴力截交法的时间复杂度为O(n2)。
• 在实际测试中，对monk模型（面片数为336974），当切片层厚为0.2mm，切片层数为877层时，使用扫描平面法（sweep）所
需的截交时间约为21秒，得到的各层截交线段总数为866540条，平均每层线段数约988条。对这些层上的截交线段，使用暴力
法进行线段拼接的总时间约为975秒，超过16分钟，平均每层拼接时间超1.1秒。
• 目标：设计高效、稳定的散乱线段拼接算法。

3.字典序排序法拼接优化
• 字典中单词的排列规则
• 如果单词中只有一个字母，那么这些单词将按照 a~z 的顺序排列，比如a在b的
前面（记为a < b），b在c的前面（记为b < c）等。
• 如果单词由 一个或两个字母 组成，那么这些单词先按照第一个字母排序 ，如果
第一个字母相等，则继续按照第二个字母排序，比如ab < b，ab < ba，ab < ac等。
• 同理，如果单词 由一个、两个或三个字母 组成，那么这些单词先按照第一个字
母排序，如果第一个字母相等 ，则按照第二个字母排序 ，如果第二个字母也相
等，则按照第三个字母排序，比如abc < bc，a < bcd，abc < acd等。
• 以此类推，可以按照这种规则对字典中所有的单词排序 ，每个单词也总能在字
典中找到一个合适的位置。

3.字典序排序法拼接优化
• 点的字典序
• 方法2：各维度坐标分别比较
• 对任意两个点P1(x1, y1, z1)和P2(x2, y2, z2)
• 首先比较两个点的X坐标：如果x1 < x2，那么P1 < P2。
• 如果x1 = x2，再比较两个点的Y坐标：如果y1 < y2，那么P1 < P2。
• 如果y1 = y2，再比较两个点的Z坐标：如果z1 < z2，那么P1 < P2。
• 通过这种比较方式，即便P1、P2坐标发生微小扰动，也不
会影响比较结果。
• 这种排序的几何意义是非常明确的 ，在二维情况下 ，左
下方的点总是小于右上方的点。

• 算法实现
• link函数是执行线段字典序拼接的核心函数，它基本还原了拼接流程：从数据点准备到第1层循环，第
2层循环等。这里数据点准备是通过函数createLpList 函数实现的。
• 在第1层循环中，通过findUnusedPnt函数从lpnts列表中找出一个没有用过的链接点，如果找不到这样的点，该函数返回–1，
否则返回一个大于等于0的点序号。如果函数findUnusedPnt返回–1，则退出第1层循环。
• 在第2层循环中，获得p.other的index值后，首先比较p.other和lpnts[index - 1]是否重合，这里将链接点转化为Point3D对象进行
比较，比较函数是isCoincide而非isIdentical，这是一种偏安全的做法，可以增强拼接算法的鲁棒性。
• link函数退出条件有两个
• 其一是正在生长的多线段poly闭合了，这种退出是正常的退出，得到的轮廓也是想要的封闭轮廓。
• 其二是当前的p.other找不到序号相邻的重合点时退出，这种退出是不正常的退出，此时得到的多段线是非封闭的，这并不是
我们想要的。
出现第二种情况的原因可能有两个：一是输入的STL模型本来就是非封闭的（有破洞或孔洞），二是STL模型中相邻面片间的缝
隙过大，这其实都是模型本身的问题。

• 字典结构：键值对，键就是两点的共同坐标，值就是被绑定的两个点对象。
• 用Python语法描述，1号点和6号点在字典中的保存形式为{(x0, y0): [lp1, lp6]}。

4.字典查询法拼接优化
• 拼接算法流程
• 输入：截交线段的列表segs
• 输出：封闭轮廓的列表contours
• 首先从dic中寻找一个从来没有被使用过的点p。因为仅在字典的值中保
存了链接点对象 ，因此遍历字典的值 （而非键），从中寻找符合要求
的点p。
• 如果不能找到这样的点，那么退出循环，输出轮廓列表contours，整个
流程到此结束；但如果能够找到没被使用过的点 p，则新建一条多段线
poly，用于收集链接点。
• 将点p作为当前点添加到多段线poly中，并设置p和p.other两点的used属
性为True，即两点已经被使用。
• 然后根据p.other的坐标在dic中查询相应的链接点列表 ，并在该列表中
选择有别于 p.other的点作为 p的更新目标 ，即设置该点为新的点 p（此
时p也有可能为空，即查询失败）。
• 判断此时 poly 是否闭合 ， 如 果 闭 合 则 将poly 添加到闭合轮廓列表
contours中，并跳出循环；如果不闭合则进一步判断 p是否为空 ，如果
为空则将poly添加到开放轮廓列表 polys中，并跳出循环 。在以上两个
条件均不成立时，则继续循环，不断从dic中收集点添加到poly中

def __init__(self): pass # 忽略之前已定义过的函数
def createLpDic(self): pass
def findUnusedPnt(self, dic): # 从字典中寻找没用过的点
for pnts in dic.values(): # 遍历字典的值（values）
for pnt in pnts: # 正常情况下，pnts包含2个元素
if pnt.used == False:
return pnt
return None # 没找到没用过的点，返回None
def findNextPnt(self, p, dic): # 根据当前点p寻找下一个点
other = p.other
pnts = dic[(other.x, other.y)] # 以点p的other坐标为键查询
difPnt = None # 不同于other的点
for pnt in pnts:
if pnt is not other: # 指针（引用、id）比较
difPnt = pnt
return difPnt # 返回找到的不同于other的点
def link(self): # 定义链接核心函数link
dic = self.createLpDic() # 首先构建字典
while True: # 第1层循环
p = self.findUnusedPnt(dic) # 寻找没用过的点p
if p is None: break # 如果没找到p则退出第1层循环
poly = Polyline() # 新建多段线poly
while True: # 第2层循环
poly.addPoint(p.toPoint3D()) # 将点p添加至poly
p.used, p.other.used = True, True # 设置p和p.other为已用
p = self.findNextPnt(p, dic) # 根据p和dic寻找下一个点
if poly.isClosed(): # 如果poly闭合则将其添加至
self.contours.append(poly) # 封闭轮廓列表contours中，并
break # 退出第2层循环
if p is None: # 如果poly不闭合则将其添加至
self.polys.append(poly) # 开放轮廓列表polys中，并
break # 退出第2层循环

def makeMessySegs(circleNum = 10, segNumPerCircle = 100000, radius = 100.0): # 函数定义
segs = [] # 定义线段列表
r = radius # 以半径递增的方式生成同心圆

pnts = [] # 点列表，用于收集圆上的点

x = r * math.cos(theta) # 圆上点x、y坐标，圆心在原点
y = r * math.sin(theta)

pnts.append(pnt) # 将点添加到pnts
pnts.append(pnts[0]) # 在pnts添加起点，以封闭轮廓
for j in range(len(pnts) - 1): # 将点依次整理为线段，添加至segs
seg = Segment(pnts[j], pnts[j+1])
segs.append(seg)
r += 10.0 # 同心圆半径递增
print('segment count:', len(segs)) # 打印segs中线段总数
print('min segment length:', segs[0].A.distance(segs[0].B)) # 打印segs中最短的线段
for i in range(len(segs)): # 对segs中线段散乱化处理
rd = randint(0, len(segs) - 1) # 生成一个随机序号
segs[i], segs[rd] = segs[rd], segs[i] # 当前线段和随机序号线段交换
return segs

本章小结
• 这一章研究了三维打印路径规划中的截交线段拼接问题，实现了两种
的线段拼接算法，即：字典序排序拼接法和字典查询拼接法。
• 前者依赖对线段端点进行字典序排序 ，从点的序号中找出相邻的重合点；
• 后者以线段端点坐标为键建立字典结构 ，从字典的键值对中查询重合点 。
• 两种方法的相同点是它们都依赖链接点（LinkPoint）数据结构。
• 两种拼接算法具有线性的运行时间，它们的性能要远远优于暴力拼接
法。就两种算法本身而言，字典查询法的性能比字典序排序法的性能
更胜一筹。
