class TFace: 
    def __init__(self, tA, tB, tC, te1, te2, te3):  # 根据拓扑点和棱边构造拓扑面 
def zMin(self)      # 获取面片 Z 方向最低点 
def zMax(self)      # 获取面片 Z 方向最高点 
def intersect(self, z):     # 面片和 z 平面求交，返回交线段或 None 
注意：intersect返回包括三个部分： 
第1 部分为 Segment 类型的线段（或 None）； 
第2 部分和第三部分为交线两个端点所在的三角面片的半边或顶点引用。如果交线的两个端点都在三角面片的半
边上，则在第二部分返回两条半边的引用；如果交线的两个端点分别在三角面片的一条半边和一个顶点上，则在第二
部分返回半边的引用； 
第3 部分返回顶点的引用。如果面片和截平面不相交或只交于一点，则返回的三部分均为 None
