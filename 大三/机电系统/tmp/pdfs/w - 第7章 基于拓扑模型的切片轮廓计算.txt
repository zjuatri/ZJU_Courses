6
 如果可以从当前面片查询相邻面片，能做什么？
① 从任意一个面片出发，求取该面片和截平面的交线。
② 查询该面片的相邻面片，并求取相邻面片和截平面的交线。
③ 查询相邻面片的相邻面片，然后求交。
④ 依此不断迭代，直至所有面片被用完。
• 在这一过程中 ，从相邻面片求得的截交线段也必然是相邻、相接的，因
此在截交过程中就可以直接对交线依次进行拼接 ，整个截交和拼接过程
将融为一体。
• 如果把第一个面片称为 “种子”，求取切片轮廓的过程类似于种子不断
“追踪”相邻面片的过程。

=== 8 ===
• 顶点拓扑结构
• 假设：STL模型中顶点不存在冗余情况（为什么？）
• 在STL模型中，每个三角面片都有独立的顶点，这导致坐标相同的顶点，各自拥有不同的顶点对象。这将增加建立顶点拓扑关系的难度。
• 理想情况下，每个顶点位置上应该只有一个顶点对象，以下将在这一理想情况下继续讨论顶点拓扑结构。
• 顶点拓扑属性
• 坐标：顶点应该拥有X、Y、Z三个方向的坐标，以指示它所在的空间位置。
• 面片：一个顶点至少被 3 个三角面片共用，因此在顶点内部，应该有一个面片指针列表，用来保存所有用到该顶点的三角面片指针（引用）。
8
是否需要保存棱边？
• 在STL模型中，一个顶点被若干条棱边共用。因此顶点理应 还有一个棱
边指针列表，用来保存所有用到该顶点的棱边指针（引用）。
• 规定：顶点不保存棱边，面片保存棱边，顶点间接索引棱边。

class TVertex: # 定义Tvertex类
def __init__(self, pnt3d, digits = 7): # 从Point3D对象初始化
self.x = round(pnt3d.x, digits) # 顶点的x、y、z坐标
self.y = round(pnt3d.y, digits)
self.z = round(pnt3d.z, digits)
self.faces = [] # 和顶点相接的面片引用
def toTuple(self): # 将顶点转化为元组
return (self.x, self.y, self.z)
def toPoint3D(self): # 将顶点转化为Point3D对象
return Point3D(self.x, self.y, self.z)
def isSmaller(self, other): # 比较两个顶点大小
if self.x < other.x: return True
elif self.x == other.x and self.y < other.y: return True
elif self.x == other.x and self.y == other.y and self.z < other.z: return True
return False

class TEdge: # 定义Tedge类
def __init__(self, tA, tB): # 从两个TVertex点初始化
self.A, self.B = tA, tB # 两个顶点引用 A、B
self.F = None # 所从属的面片引用 F
self.OE = None # 对边引用 OE
def toTuple(self): # 将边转化为元组（6维）
if self.A.isSmaller(self.B):
return (self.A.x, self.A.y, self.A.z, self.B.x, self.B.y, self.B.z)
else:
return (self.B.x, self.B.y, self.B.z, self.A.x, self.A.y, self.A.z)
def intersect(self, z): # 边和z平面求交，返回交点
if min(self.A.z, self.B.z) > z or max(self.A.z, self.B.z) < z:
return None # 如果边高于或低于z，无交点
elif self.A.z == self.B.z == z:
return None # 如果边位于z平面，无交点
else:
if z == self.A.z: return self.A.toPoint3D()
else:
ratio = (z - self.A.z) / (self.B.z - self.A.z) # 根据z比例计算
vec = self.A.toPoint3D().pointTo(self.B.toPoint3D()).amplified(ratio)
pnt = self.A.toPoint3D() + vec
return pnt

• 面片拓扑结构
• TFace 类包含 7 个属性，它们分别是A、B、C、E1、E2、E3以及used。
• A、B、C：面片的顶点引用，它们并非单独属于某个面片，而是同时由某几个面片共享；
• E1、E2、E3：分别为面片的半边引用，在半边初始化时，规定E1为由顶点A、B构成的半边，E2为由顶点B、C构成的半边，
E3为由顶点C、A构成的半边，这一规定非常重要，必须遵照执行；
• used：表示当前面片是否已经被使用过，该属性将在后面截交计算时用到。
• zMin 和 zMax 函数分别用于获取面片3个顶点在Z方向上极小值和极大值。
• intersect函数，这个函数的功能是计算当前三角面片和截平面的交线，它是后面切片轮廓计算的核心基础函数。它
的实现原理和之前在GeomAlgo模块中实现的 intersectTrianglePlane 函数完全一样。（为什么又重新实现一遍？）
• intersectTrianglePlane返回是Segment类型的截交线段或None，其中None表示三角面片和截平面不相交。
• intersect的返回相对复杂，包括三个部分：第一部分为Segment类型的线段（或None），第二部分和第三部分为交线两个端点
所在的三角面片的半边或顶点引用。如果交线的两个端点都在三角面片的半边上，则在第二部分返回两条半边的引用；如果

3.STL拓扑模型重建
• 冗余顶点消除
• 问题背景：对输入的STL模型，如果从每个独立的三角面片中收集顶点坐标 ，并把这些顶点全部保存到一个 顶点
列表（数组）中，根据欧拉定理，顶点列表中大概有 六分之五的元素的冗余的 ，具有相同坐标的顶点被不断重复
保存，只有六分之一的顶点是有用的。
• 问题抽象：对一个可能保存了相同元素的列表 ，如何以最快的速度得到它的 unique列表。这里unique列表的意思
是列表中的元素各不相同。
19
一种思路：排序以消除相同元素
• 排序完成后，在列表中，具有相同值的元素被排在的相邻的位置上。
• 从列表的第一个元素开始 ，逐个比较相邻元素对的值是否相等 ，如果
相等，则移除其中一个元素，直至列表末尾。
• 时间复杂度O(nlog(n)).


=== 20 ===
3.STL拓扑模型重建
• 冗余顶点消除
• 排序法确实能够消除冗余顶点 ，得到一个毫无冗余的顶点列表之后 。但无益于顶点、棱边、面片的拓扑关系建立 。
• 排序过程会完全打乱顶点顺序，很难回溯哪个顶点属于哪个面片、哪条棱边。

• 借助字典vxDic，对STL模型中的每个三角面片不断重复上述过程，就可以消除冗余顶点。
• 由于字典查询的时间复杂度为O(log(n))，因此使用字典消除冗余顶点总的时间复杂度为O(nlog(n))，其
中n为STL模型总顶点数，包含冗余顶点。
• 优势：以三角面片为单元消除冗余顶点，同时可整理顶点、棱边、面片拓扑关系。

• 基本现象
• 在切片过程中，如果当前截平面和STL模型中的其中一个三角面片相交，那么截平面也必然会和这个面片的其中一个（或两个）

4.拓扑模型切片
• 寻找种子面片（Finding Seed）
• 问题描述：设当前的截平面高度为z，在拓扑模型中寻找一个面片，即种子面片，使其满足和截平面相交。
• 暴力寻找：遍历拓扑模型中的所有面片 ，检查当前面片是否和截平面相交 ，如果相交，则设该面片为种子面片 ，并退出遍历循环。
——判交而非求交
• 在以上遍历过程中，不用去求每个面片和截平面的截交线，因为这样可能消耗大量的计算时间。
• 只需判断每个片面的最低点和最高点组成的范围[zMin, zMax]是否包含截平面高度z值，如果包含，说明当前面片可能和截平面相交
• 暴力法的问题
• 寻找一个种子需要遍历模型中所有面片，效率低！
• 如果当前截平面上有多条截交轮廓，那么需要遍历多次模型以找出种子。
• 注意：在当前高度上 ，一个三角面片和截平面至多相交一次 ，因此，计算中，如果三角面片和截平面相交 ，则设置面片的used属
性为True，表示其已使用过。为什么？

• 输入：截平面高度z，面片列表faces。
• 输出：包含了当前层切片轮廓信息的layer。
• 对faces清洗：将faces中每个面片的used属性值置为False。 ——非常重要！
• 两层循环
 第1层循环主要做的就是从faces中找出一个种子面片：如果找不到种子面片 ，表明faces中所有
面片均已被使用，此时可以输出切片数据layer，并退出整个流程；如果能够找到种子面片，则
新建一条Polyline类型的轮廓做为当前轮廓contour，并进入第2层循环。
 第2层循环的核心功能就是不断根据当前面片寻找与之相邻的下一面片 ，并在这一过程中，把
截交得到线段添加到当前轮廓。
• 退出条件（第2层循环）
 （1）当前面片和截平面不相交 ，这个条件在正常情况下似乎很难满足 ，除非有现在还没预料
到的异常发生，这是因为在第2层循环中，通过findNextFace函数寻找当前面片，如果它找到的
面片和截平面不相交 ，那它就直接返回 None。为了保证流程的稳定性和鲁棒性 ，在流程中保
留这个退出条件。
 （2）当前轮廓contour已封闭，这是理所当然的正常退出 ，当前轮廓封闭后，应该再寻找一个
种子面片。
 （3）根据当前面片找不到目标邻面 ，即findNextFace返回None，这表明模型在当前面片处未
封闭或存在裂缝，这是不正常的，也是不应该发生的，如果在循环中遭遇了这个退出条件，将
得到一条非封闭的轮廓线。
• 如果轮廓中包含的点的数量大于 0，则将该轮廓添加至 layer，否则直接放弃当前轮廓 。

4.拓扑模型切片
• 切片轮廓创建
• createLayerContour函数中，对得到的截交线段，通过Polyline类的appendSegment函数将其添加到当前轮廓中。
• 在每一步循环中，尽管得到的截交线段必然是可以被直接添加到当前轮廓上的，但是不太确定的是，它到底是和当前轮廓的头部还是尾部相接。
• 从理论上分析，对于一条新建的空轮廓，在对其添加第1条截交线段时可以不在意它的方向，但在添加第2条线段时，就要考虑一下它的走向。
• 如果第2条线段是被拼接在了轮廓尾部，那么由追踪截交的原理可知，以后每条线段都将被拼接在轮廓尾部；而如果第2条线段被拼接在了轮廓头
部，那么以后每条线段也都将被拼接在轮廓头部。
• 最好不要将线段拼接到轮廓头部的，因为对于大都编程语言的动态数组来说，在数组头部插入一个数据的效率是低于在尾部添加一个数据的。
• 以上代码选择了一种偷懒的方式，直接调用了appendSegment函数，让这个函数去判断到底应该将线段拼接到轮廓的头部或尾部。

本章小结
• 这一章另辟蹊径，介绍并实现了基于拓扑模型的切片轮廓计算方法 ，它的
功能相当于第五章介绍的截交算法和第六章介绍的拼接算法的总和 ，能够
一步到位地从STL模型获取切片轮廓数据。
• 首先介绍了立体几何中顶点、棱边以及面的拓扑关系表示方法，包括从顶点索引到面，从面
索引到顶点和半边，从半边索引到顶点、面以及对边。
• 在此基础上，运用字典结构对输入的STL模型进行了拓扑重建，同时消除了模型中的冗余顶
点。
• 对得到的拓扑模型，首先使用扫描平面框架快速获取指定层高上和截平面相交的所有三角面
片。然后我们从中挑选一个种子面片，并从这个种子面片出发，根据模型中点线面的拓扑关
系，不断追踪、截交目标邻面，最终得到封闭轮廓。
• 最后，对本章介绍的拓扑切片方法和基于第五、六章的组合切片方法进行了测试比较，结果
表明：模型中面片数量越多、切面层厚越小，拓扑切片的优势越明显。
