## 机械设计练习题：弹簧（完整选项版）

### 一、判断题

* **C1601** 圆柱螺旋弹簧的弹簧指数（旋绕比）为簧丝直径与弹簧中径的比值。 ( **×** )
  * **解析**：旋绕比 $C$ 定义为中径与直径之比，即 $C = D_2 / d$。
* **C1602** 圆柱拉伸螺旋弹簧工作时簧丝的应力为切应力。 ( **√** )
* **C1603** 圆柱拉伸、压缩螺旋弹簧工作时簧丝截面上最大切应力 $\tau_{max}$ 发生在弹簧圈内侧。 ( **√** )
  * **解析**：受曲率及剪力叠加影响，内侧应力最集中。
* **C1604** 其他条件相同，簧丝直径越大，圆柱拉伸、压缩螺旋弹簧最大切应力 $\tau_{max}$ 越大。 ( **×** )
  * **解析**：$\tau \propto 1/d^3$，直径越大，应力越小。
* **C1605** 其他条件相同，簧丝直径越小，圆柱拉伸、压缩螺旋弹簧的变形量越大。 ( **√** )
  * **解析**：变形量 $\lambda \propto 1/d^4$，直径越小，弹簧越软，变形越大。
* **C1606** 圆柱拉伸、压缩螺旋弹簧强度计算的目的在于确定弹簧的有效工作圈数。 ( **×** )
  * **解析**：强度计算定直径 $d$，刚度计算定圈数 $n$。
* **C1607** 圆柱压缩螺旋弹簧两端需制作挂钩。 ( **×** )
  * **解析**：拉伸弹簧需挂钩，压缩弹簧通常端面并紧磨平。
* **C1608** 弹簧卸载过程时如有外部摩擦产生的摩擦热而消耗一部分能量 $U_0$。与加载过程变形能 $U$ 的比值越大，该弹簧缓冲吸振的效果越佳。 ( **√** )
* **C1609** 测力弹簧应采用变刚度弹簧。 ( **×** )
  * **解析**：应采用恒刚度弹簧以保证读数线性。
* **C1610** 橡胶弹簧由于材料内部的阻尼作用，在加载、卸载过程中摩擦能耗大，吸振缓冲效果好。 ( **√** )
* **C1611** 一般情况下，弹簧簧丝直径应由弹簧的刚度计算确定。 ( **×** )
* **C1612** 圆柱扭转螺旋弹簧强度计算是使其最大扭剪应力不超过弹簧簧丝材料的许用扭剪应力。 ( **×** )
  * **解析**：扭转弹簧主要受弯曲应力。
* **C1613** 圆柱压缩螺旋弹簧用强度计算确定簧丝直径，材料为碳素弹簧钢丝时许用切应力与强度极限有关，而碳素弹簧钢丝的强度极限又与簧丝直径有关，因此需先假定簧丝直径进行试算。 ( **√** )
* **C1614** 为使圆柱压缩螺旋弹簧可靠地安装在工作位置上应预加初始载荷。 ( **√** )

### 二、选择题

* **B1601** 圆柱螺旋弹簧簧丝直径为 $d$，弹簧中径为 $D_2$，弹簧外径为 $D$，弹簧内径为 $D_1$，则弹簧指数 $C$（旋绕比）=（ **B** ）。
    * A. $D/d$
    * B. $D_2/d$
    * C. $D_1/d$
    * **解析**：标准定义 $C = D_2 / d$。

* **B1602** 圆柱螺旋弹簧在自由状态下的弹簧节距为 $t$，弹簧外径为 $D$，弹簧中径为 $D_2$，则弹簧螺旋升角 $\alpha$ =（ **B** ）。
    * A. $\arccos \frac{t}{\pi D_2}$
    * B. $\arctan \frac{t}{\pi D_2}$
    * C. $\arcsin \frac{t}{\pi D}$
    * **解析**：$\tan \alpha = \text{对边}/\text{邻边} = t / (\pi D_2)$。

* **B1603** 圆柱压缩螺旋弹簧簧丝应力为（ **B** ）。
    * A. 压应力
    * B. 切应力
    * C. 压应力与切应力的复合应力
    * **解析**：虽然整体受压，但簧丝微观受力为扭转产生的切应力。

* **B1604** 圆柱压缩螺旋弹簧的最大切应力 $\tau_{max}$ 发生在簧丝的（ **A** ）。
    * A. 内侧
    * B. 中心
    * C. 外侧
    * **解析**：内侧曲率大且切应力方向一致，产生最大应力。


* **B1605** 其他条件不变，当簧丝直径增加时，圆柱压缩螺旋弹簧的最大切应力 $\tau_{max}$（ **B** ）。
    * A. 增大
    * B. 减小
    * C. 不变
    * **解析**：直径 $d$ 增加，截面抗扭能力增强，应力减小。

* **B1606** 其他条件不变，当弹簧的旋绕比增加时，圆柱压缩螺旋弹簧的最大切应力 $\tau_{max}$（ **A** ）。
    * A. 增大
    * B. 减小
    * C. 不变
    * **解析**：$C$ 增大说明中径 $D_2$ 变大，力臂变长，扭矩增加。

* **B1607** 在一般情况下，圆柱拉伸和压缩螺旋弹簧的刚度与（ **D** ）无关。
    * A. 簧丝直径
    * B. 旋绕比
    * C. 圈数
    * D. 作用载荷
    * **解析**：刚度由材料 $G$ 和几何尺寸 $d, C, n$ 决定，与外载荷无关。

* **B1608** 旋绕比 $C$ 或工作圈数减少，都会使圆柱拉伸和压缩螺旋弹簧的刚度增大，而旋绕比对刚度的影响比工作圈数对刚度的影响（ **A** ）。
    * A. 更大
    * B. 更小
    * C. 相同
    * D. 不一定
    * **解析**：刚度 $k \propto d^4 / (C^3 n)$，显然 $C$ 的三次方影响大于 $n$ 的一次方影响。

* **B1609** 圆柱扭转螺旋弹簧簧丝所受应力为（ **B** ）。
    * A. 扭剪应力
    * B. 弯曲应力
    * C. 扭剪与弯曲复合应力
    * **解析**：扭转弹簧在工作时，簧丝受力类似于受弯的梁。

* **B1610** 对圆柱压缩螺旋弹簧进行稳定性验算，其验算指标为（ **C** ）。
    * A. 有效工作圈数
    * B. 弹簧的自由高度
    * C. 自由高度和弹簧中径之比
    * D. 有效工作圈数与自由高度之比
    * **解析**：稳定性取决于长径比 $b = H_0 / D_2$。
